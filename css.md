## 1. Objetivo

Interfaz clara y responsive: cabecera con idiomas, formularios centrados, editor usable, galería en grid.

Variables CSS (`--primary-color`, etc.) y utilidades para botones, cards, flash messages.

---

## 2. Zonas críticas

| Zona | Clases / ideas |
|------|----------------|
| Header | `.header-bar`, switcher de banderas |
| Home | `.features-grid` 2×2 |
| Editor | tabs, `#drop-zone`, stickers |
| Auth | `.auth-card` centrada |

Media queries para una columna en móvil.
